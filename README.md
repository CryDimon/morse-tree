# Morse Tree

Тренажёр азбуки Морзе в виде дерева, как на карточке: точка — кружок, тире — прямоугольник.

- **Дерево**: стучи ключом и смотри, как загорается путь по дереву.
- **Расшифровка**: принимай сигнал звуком, светом или знаками и называй букву или слово.
- **Передача**: передай показанную букву ключом.
- **Очки**: начисляются за скорость ответа, за серию без ошибок (до ×4) и за сложность подсказки (вслепую ×2). Есть уровни, дневная цель и серия дней.
- Три набора: латиница, русский алфавит и цифры. У каждого свой прогресс.
- Знаки открываются по мере освоения: от корня дерева вниз.
- В расшифровке ответ можно вводить с клавиатуры в любой раскладке.

Управление: пробел — ключ, ← тире, → точка, Enter — конец буквы.
